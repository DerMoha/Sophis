Support / Hilfe

Report bugs and ask questions on Sophis GitHub Issues. A GitHub account is needed to post.

Include your app version, iOS version and steps to reproduce the problem. Issues are public: do not include API keys, passwords, health records or private photos.

Für Hilfe oder Fehlerberichte nutze die GitHub-Issueseite. Bitte veröffentliche dort keine privaten Gesundheitsdaten, Fotos oder Zugangsdaten.

Account and data deletion

You can delete your optional partner account in the app. Delete local tracking data separately in Settings. Contact the maintainer through the GitHub profile for private inquiries using the contact options available there.
